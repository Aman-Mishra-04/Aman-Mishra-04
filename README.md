## 💻 Featured Project

### 🧠 Mansik Santulan Score — ML-Based Mental Health Analysis

An ML-powered web application that analyzes the relationship between students' social media usage, lifestyle habits, and mental well-being to predict a mental health score.

**✨ Key Features**
- Predicts a mental health score using machine learning.
- Analyzes screen time, sleep hours, study hours, physical activity, and stress levels.
- Provides an interactive web interface.
- Uses a REST API for model predictions.

**⚙️ Tech Stack**

`HTML` `CSS` `JavaScript` `Python` `FastAPI` `Scikit-learn` `Pandas` `Joblib` `Pydantic`

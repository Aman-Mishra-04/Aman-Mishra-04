## 🚀 Featured Projects

### 🧠 Mansik Santulan Score – ML-Based Mental Health Analysis

A Machine Learning-based web application that analyzes the relationship between students' social media usage, lifestyle habits, and mental well-being.

The application uses a trained ML model to predict a mental health score based on factors such as screen time, sleep hours, study hours, physical activity, and stress levels.

**Tech Stack:**

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI, Uvicorn
- Machine Learning: Scikit-learn, Pandas, Joblib
- Data Validation: Pydantic

**Key Features:**

- ML-based mental health score prediction
- Analysis of social media usage patterns
- Lifestyle and stress-related input analysis
- Interactive web interface
- REST API integration for model predictions
